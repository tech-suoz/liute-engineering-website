# Premium image slots (homepage)

Drop licensed, high-resolution JPGs into `assets/images/premium/` using the exact filenames below. The homepage picks them up automatically;
until a file exists the site shows the previous image, so nothing breaks. Replaced slots are labelled "Illustrative image"; slots still showing
a LIUTE field photo are labelled "LIUTE project photo". Never present stock images as LIUTE projects.
Record each image's source and licence in `IMAGE-CREDITS.md`.

Sizes: hero 2400x1350; tall side/slider images 1600x2000; tiles 1600x1200; backgrounds 2400x1500. Compress to ~250-400 KB.
Style: cool blue/graphite tones, real equipment, sharp detail. No handshakes, no staged laptop shots.
